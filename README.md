# SUSANIN BIKE

Лендинг проката эндуро-мотоциклов в Сусанинском районе Костромской области.

Репозиторий: https://github.com/Gennadiy-ai/susanin-bike-site

## Стек

Статический сайт: HTML/CSS/JS, без сборки и зависимостей.

- `index.html` — разметка
- `css/style.css` — стили
- `js/main.js` — интерактивность (навигация, FAQ-аккордеон, модалка записи, форма)
- `images/` — фото

## Запись

Кнопка «Записаться» открывает модальное окно с формой (тариф, дата, число людей, контакты). При отправке форма шлёт данные через Formspree (эндпоинт нужно указать в `js/main.js` в переменной `FORMSPREE_ENDPOINT`), либо — если эндпоинт не настроен — открывает `mailto:` со всеми данными заявки.
