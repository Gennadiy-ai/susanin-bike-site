# SUSANIN BIKE

Лендинг проката эндуро-мотоциклов в Сусанинском районе Костромской области.

Репозиторий: https://github.com/Gennadiy-ai/susanin-bike-site

## Стек

Статический сайт: HTML/CSS/JS, без сборки и зависимостей.

- `index.html` — разметка
- `css/style.css` — стили
- `js/main.js` — интерактивность (навигация, FAQ-аккордеон, запись через ВК)
- `images/` — фото

## Запись

Кнопка «Записаться» (шапка, мобильное меню, hero) открывает диалог с сообществом ВКонтакте — `window.open('https://vk.com/write-228039638', ...)` (ID группы в `js/main.js`, константа `VK_GROUP_ID`). Тариф, дату и контакты посетитель указывает сам в переписке с группой; отдельной формы и модального окна на сайте больше нет.

## Аналитика

Яндекс.Метрика (счётчик `111996324`) в `index.html`. Цели заведены через код, не через no-code CSS-селектор: функция `reachGoal()` в `js/main.js` вызывается на всех элементах с `[data-vk-goal]` — `vk_write_click` (кнопки «Записаться» + плитка «Написать») и `vk_group_click` (ссылка на группу в «Локации»). Идентификаторы целей должны точно совпадать с тем, что заведено в интерфейсе Метрики (тип «Совпадает»).
